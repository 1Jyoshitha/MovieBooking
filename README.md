
## Overview
The **MOVIE BOOKING** is a full-stack web application built using the **MERN** stack, which consists of **MongoDB**, **Express.js**, **React.js**, and **Node.js**. This project serves as a template to help developers quickly set up a modern, scalable web application. It includes the necessary configurations and boilerplate code to get started with full-stack development.

This project can be used as a starting point for any web application requiring a backend API, front-end user interface, and database storage.

## Features
- **Full-Stack Application**: Includes both front-end (React) and back-end (Node.js + Express) components.
- **MongoDB Integration**: Uses MongoDB as the NoSQL database to store and manage data.
- **User Authentication**: Provides built-in user authentication with JWT (JSON Web Tokens) for secure login.
- **Responsive UI**: The front-end is built with React and is fully responsive to work on mobile and desktop devices.
- **CRUD Operations**: Supports basic CRUD (Create, Read, Update, Delete) operations for managing resources.
- **RESTful API**: The backend is structured around a RESTful API for easy interaction with the front-end.

## Technologies Used
- **MongoDB**: Database for storing user data and application-related information.
- **Express.js**: Web application framework for Node.js that simplifies the development of server-side logic.
- **React.js**: JavaScript library for building user interfaces with reusable components.
- **Node.js**: JavaScript runtime for executing server-side code.
- **JWT**: Authentication mechanism using JSON Web Tokens.
- **Axios**: HTTP client for making API requests from React.

## Installation
To set up the **MERN Project** locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/1Jyoshitha/Mern_project.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Mern_project
   ```

3. Install dependencies for the back-end (Node.js + Express):
   ```bash
   cd backend
   npm install
   ```

4. Install dependencies for the front-end (React):
   ```bash
   cd frontend
   npm install
   ```

5. Start the back-end server:
   ```bash
   cd backend
   npm start
   ```

6. Start the front-end server:
   ```bash
   cd frontend
   npm start
   ```

This will launch the front-end on `http://localhost:3000` and the back-end on `http://localhost:5000`.

## Usage
1. **User Registration**: Users can create an account by providing a username, email, and password.
2. **Login**: Registered users can log in with their credentials to access secured areas of the application.
3. **CRUD Operations**: Users can interact with the backend API to create, read, update, and delete resources.
4. **Responsive Interface**: The user interface adjusts to different screen sizes for an optimal experience on both mobile and desktop devices.
